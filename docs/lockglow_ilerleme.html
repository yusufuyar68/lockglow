Telefona kurmak için senin adımın

  1. App Store Connect'e girappstoreconnect.apple.com adresinde Apple hesabınla gir. Sağ üstte ekip "Yusuf Uyar" olmalı.
  2. API anahtarı oluştur ve indirUsers and Access → Integrations → App Store Connect API → Team Keys → "+" · ad: GitHub Lockglow · erişim: Admin (imza sertifikası için gerekli) · Generate, sonra Download. Dosya yalnızca bir kez inebilir. İlk kez giriyorsan önce "Request Access" çıkabilir.
  3. Betiği çalıştırTerminal sekmesine yapıştır; Issuer ID sorulunca sayfadaki kodu yapıştır.
    powershell -ExecutionPolicy Bypass -File tools\testflight_anahtar_ekle.ps1
  4. Claude'a "tamam" yazYüklemeyi Claude başlatır; test grubunu senin onayınla kurar. Sonra iPhone'a TestFlight uygulamasını kurup daveti kabul edersin.
